## 优化线和国际线差在哪

差在回国路由，不在机房位置。两条线都在东京，机器规格一样，走的路由不一样。

Premium 优化线的三网回程实测都经过中国电信 CTGNet 精品线路再转 163 骨干。广州方向的数据是：电信 49–55ms，联通 51–63ms，移动 48–59ms，移动那一跳中间出现过 153ms 的节点。另一份测评测出的全国三网平均延迟 65ms（电信 65、联通 64、移动 66），本地 ping 97ms，基本不丢包。这个水平对日本机房来说属于正常偏好的一档。

Global 国际线的国内平均延迟是 59ms。电信和联通去程回程都走 NTT 直连东京，移动去程绕美国圣何塞再回日本，回程大部分节点直连。也就是说，移动用户走国际线时，去程那一段是绕路的，延迟会比电信联通高。

两条线的平均延迟数字（65ms 和 59ms）看起来差不多，实际差别在稳定性和绕路概率上。Premium 是专门为回国流量调过的路径，Global 是“能直连就算不错”的国际线。测速方面，Premium 30M 机型上下行都能跑到 30–32Mbps；Global 100M 机型到国内、亚洲、美国节点都能跑满 100M，上下对等。

自己验最直接，两个官方测试 IP：Premium 是 **154.213.178.254**，Global 是 **154.213.191.254**，ping 一下再决定。

选择规则很简单：访客主要在国内，多花的那点钱买的是回程路由质量；访客在海外，或者你只是拿它做中转、跑国际业务，Global 的 100M 带宽更划算。

## 1核1G 够不够用

够跑小站，不够跑数据库。

第三方测评做过一组建站实测：1核1G 的机器装宝塔面板加默认 LNMP 环境后，剩 465MB 内存、37GB 硬盘，搭个小网站资源够用。测评者也提到，如果要正经建站，建议加内存，Lightlayer 支持单独加硬件。

硬件本身不弱。CPU 是 AMD EPYC 7702（另一份测评的机器是 EPYC 772），KVM 虚拟化，单核 sysbench 1640 Scores。硬盘 1M 块顺序读写 698MB/s，fio 1m 块读 413MB/s、写 440MB/s，另一份测评测出的平均读写是 650MB/s。这几个数字属于同价位里偏好的水平。

问题在 4K 随机读写：**3.23MB/s 读、3.25MB/s 写，约 800 IOPS**。这是整份测评里最弱的一项，也是决定它能不能跑数据库的关键。MySQL 这类应用吃随机 IO，800 IOPS 撑不住并发写入。

所以边界是这样的：静态站、WordPress 小博客、轻量 API、代理转发、图床、监控探针，1核1G 够用。要跑数据库、要扛并发、要做高频读写，直接往上加内存和核心，或者换独立服务器。另一点，默认给了 8GB 虚拟内存（swap），占的是硬盘空间，用不上可以自己调小。

## 30Mbps/200GB 和 10Mbps 不限流量，钱花在哪

同样 1核1G，价差来自带宽和月流量的组合，不是配置差异。算一下就知道该怎么挑。

30Mbps 满速约 3.75MB/s，一小时跑 13.5GB，200GB 大约 15 小时满速用完。适合流量不大、但需要瞬时速度的场景：网页打开、API 响应、图片加载，这些都是一阵一阵的，30M 的峰值体验明显好过 10M。

10Mbps 满速 1.25MB/s，一天不间断跑也就 108GB 左右。适合长期挂机、持续往外吐流量的场景：数据同步、备份、转发、下载中转。这类业务对峰值不敏感，对“跑多少都不额外收钱”敏感。

Global 的 100Mbps/1TB 是第三种取舍：12.5MB/s 满速，1TB 大约 22 小时跑满。带宽大、流量中等，适合有突发大带宽需求但月总量可控的项目。

限流量的档位要自己盯用量，超了通常是限速或额外计费，具体规则在下单页确认。不限流量也不是无限速，带宽上限写多少就是多少。

## IP 和流媒体：别把解锁当承诺

同一个机房，不同机器开出来的 IP 结果可能完全不一样。两份测评就是现成的例子。

一份开出的是日本 IP（AS984 OCTOPUS WEB SOLUTION，东京），流媒体检测结果：Netflix 日本区可解锁、YouTube Premium 显示美区、Amazon Prime Video 日本区可解锁；Disney+ 显示 IP 被封，Claude 不可用，Spotify 注册不可，TikTok 区域识别为菲律宾，Reddit 不可。IP 质量方面，滥用得分 0、威胁级别 low，313 项 DNS 黑名单检测里有 9 项 blacklisted、19 项 other，Google 搜索可行性显示 NO。

另一份随机开通的 Global 国际线机器，被检测脚本识别成**德国原生 IP**，能解锁德国 TikTok、德国 Netflix 和部分欧洲流媒体。IP 库认为机房在东京、两个 type 值都是 isp，多数库判为家宽，一个库判为机房，ping0.cc 判为机房且风险高。测评者的原话是：日本双 ISP 是肯定的，是不是家宽、纯净度如何有争议。

结论是不确定性太大。商家没有宣传过这些套餐带流媒体解锁，也不该为了“能看 Netflix”去买。要稳定解锁某个平台，去找明确标注解锁能力的产品，别赌开机器的手气。
